# Poke 想把 AI Agent 做成“发消息”这件小事，真正危险的是它太顺手了

4 月 8 日，TechCrunch 报道了一家叫 Poke 的新创公司。它做的不是一个新的聊天机器人，而是把 AI agent 直接塞进了你最熟悉的入口：iMessage、短信、Telegram，部分市场还包括 WhatsApp。

这件事听起来很轻，但产品判断其实很重。

过去一年，大多数 agent 产品都在拼“能力边界”：会不会调工具、会不会自动化、会不会跨应用执行任务。Poke 反着来，它先不强调复杂能力，而是先解决一个更现实的问题：普通人到底愿不愿意为了 agent 换一个入口、装一个新 App、重新学一套操作方式？

它给出的答案很直接：别折腾用户，直接把 agent 放进消息框。

## 这条路线为什么值得盯

Poke 当前支持的场景很务实：日程提醒、邮件监控、天气和出行提醒、健康与运动跟踪、智能家居控制、照片处理等。换句话说，它不从“问答”切入，而从“代办”切入。

这意味着 agent 的价值判断也在变化。

传统聊天模型的核心指标是“回答得像不像人”；但消息式 agent 的核心指标，是“能不能稳定替你把小事做完”。一旦产品进入这个阶段，竞争壁垒会从模型参数转向工作流整合、权限管理、可靠触发和低摩擦交互。

Poke 让人警觉的地方，不是技术听上去多炸裂，而是它把复杂能力伪装成了一个几乎没有学习成本的动作：发条消息。

## 行业含义：AI agent 正从工具栏走向消息层

如果这类模式跑通，影响最大的不是现有聊天机器人，而是各种“轻自动化工具”。用户过去可能要在待办 App、日历 App、邮件规则、IFTTT、智能家居面板之间来回跳，以后有可能被一个消息线程慢慢吞掉。

对平台来说，消息层一旦成为 agent 的主要入口，分发权就会重新洗牌：谁离用户日常沟通最近，谁就更容易截获任务请求。

## 受益方向

美股里，最直接的映射不是单一上市公司，而是三类资产：

第一类是通信平台和操作系统生态。Apple、Meta 这类掌握消息入口和设备权限的公司，长期更容易拿到 agent 分发红利。

第二类是自动化和 SaaS 基础设施。Twilio、Zapier 路线上的能力，未来会被重新包装成“agent 执行动作层”。

第三类是模型和推理基础设施。Poke 这种产品本身未必先赚钱，但它会持续抬高后台模型调用、记忆存储和触发式推理的需求。

A 股对应更值得看“入口+自动化+企业软件”三条线：办公协同、客服自动化、企业微信生态、智能硬件联动相关公司，逻辑都会被重新估值。

## 一句话判断

Poke 不是在证明 AI agent 又能做什么新花样，它是在证明一件更现实的事：当 agent 被塞进最普通的消息框里，用户接受度可能会比行业预期来得更快。
